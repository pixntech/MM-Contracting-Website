# MM Contracting — Real Projects Patch

Replaces the fictional project portfolio and stock gallery data with the project names and two project images supplied in the MM Contracting company profile slide.

Project groups added:
- Industrial Buildings
- Educational Buildings
- Residential Buildings
- Commercial & Administrative Buildings

The patch intentionally does not invent project years, values, clients, status, or locations that were not present in the supplied source.

It also replaces the current stock-image gallery dataset with the two real images supplied in the slide.

The patch backs up affected files and does not touch `.env`, `node_modules`, `.git`, certificates, or contact/company data.
