# MM Contracting — Real Certificates Patch

This patch replaces the placeholder certificate dataset with the real company documents supplied by the project owner.

Included documents:
- Taxation Card No. 313-274-584
- Value Added Tax Registration Certificate
- Egyptian Federation for Construction & Building Contractors Membership No. 63029
- Commercial Register No. 415939
- Partnership Contract

The 9 supplied scans are grouped into 5 document cards. Multi-page records can be browsed page-by-page inside the certificate viewer.

Images were cropped from the presentation screenshots and stored locally as optimized WebP files.

The patch does not touch `.env`, `node_modules`, or `.git`, and creates a timestamped backup before overwriting existing files.
